# ASF 판매자 후보 자동 탐색과 분류

> 이 저장소는 실제 인턴 및 별도 프로젝트 경험을 설명하기 위해 새로 작성한 공개 포트폴리오입니다. 회사의 원본 소스, 데이터베이스, 고객 정보, 운영 설정, 인증정보를 포함하지 않습니다. demo.py와 예시 데이터는 2026년에 처음부터 작성한 독립적인 오프라인 재현 예제로, 2024년 실제 운영 코드를 복제하거나 당시 배포 사실을 증명하지 않습니다.

**기간:** 인턴: 2024.07~09  
**실제 업무 기술:** Python, Selenium, BeautifulSoup, 정규표현식, Excel

## 배경과 해결하려던 문제

기존 후보 목록에서 관계 및 프로필 정보를 확인하고, 반복적으로 후보를 판별하는 작업을 줄이는 것이 목적이었습니다.

## 직접 수행한 작업

- 판매자 후보의 프로필과 관계 정보 수집 흐름을 설계하고 구현했습니다.
- 프로필 내용과 팔로워 정보를 기준으로 후보 분류 로직을 작성했습니다.
- 중복 처리와 점진적 저장을 통해 반복 수집 결과를 관리했습니다.
- 수집 과정의 예외 상황을 고려해 자동화 동작을 점검했습니다.

## 기여 범위 및 사실 확인

실제 플랫폼의 계정 목록, 거래처 식별정보, 선별 기준 상세값은 공개하지 않습니다. 데모의 판단 규칙은 포트폴리오용 가상 규칙입니다.

## 공개 오프라인 데모

가상 프로필의 중복 제거, 최소 조건 검사, 키워드 분류와 CSV 내보내기를 재현합니다. 웹 크롤링을 실행하지 않습니다.

```bash
python demo.py
python -m unittest discover -s tests -v
```

Python 3.10 이상을 권장합니다. 외부 API 키나 실서비스 계정이 필요하지 않습니다.

## 확장된 ASF 오프라인 파이프라인

`asf_engine.py`는 검증 가능한 가상 후보 데이터로 중복 처리, 분류, SQLite 저장과 변경 이력을 재현합니다. `run_pipeline.py`는 JSON 입력을 받아 후보 결과를 CSV로 내보내며, 같은 DB로 재실행해도 레코드가 중복되지 않습니다.

```bash
python run_pipeline.py --db synthetic_demo.sqlite --export candidate_export.csv
python -m unittest discover -s tests -v
```

[설계 흐름과 범위](docs/PIPELINE.md). 후보 필터 조건은 실제 회사 정책이 아닌 공개용 예시입니다.
